# ADR-MA-001 · 执行授权与模型评分分离

状态：Proposed，2026-11-06；作者工作流：马祥珲，AI 辅助。产品控制边界沿用 SRS；本文实现方案待组内评审。

## 问题与约束

UPS 的预测集合、TAIL-Safe 的 Q、规则相似度和本项目的成功率估计语义不同。任何高分都不能证明动作合法、机器人静止或任务最终成功。SRS FR03/06–09、DR04、NFR05/06、AI04 已约束控制权、时效和独立停止。

## 备选

| 方案 | 收益 | 代价/风险 |
| --- | --- | --- |
| 策略直接向 adapter 派发 | 路径短 | 授权、日志和停止难以统一，违背 SRS |
| 一次入口检查后信任算法 | 实现简单 | 推理期间暂停/超时造成竞态，旧结果可能执行 |
| 协调器集中授权，入口/派发复检 | 约束可追踪、算法可替换 | 增加快照比较、原子接纳和取消逻辑 |

## 拟议决定

采用第三方案。模型只输出提案；协调器在序列化边界复检代次、时效、预算、动作和授权，持久化 intent/计次后派发。模型评分不解锁停车，校准概率与 rank/Q 分开。0.60 门槛沿用 SRS 暂定值，不以文献数字替换。

规则对照的评分与门禁须明确实现并评审；不存在校准路径时保持不可自动执行，不能给规则动作伪造概率。在线默认本地处理，不因 UPS 使用 VLM 就发送本项目观测到第三方。

## 后果、验证与重审

收益：避免旧代、过期和越界动作；便于测试。代价：模型升级需版本/校准兼容检查；两次检查增加延迟。PoC：高分旧代、暂停竞态、重复决定、日志失败、rank误作概率、停止未确认等负例不得执行；对 T02/T04/T07/T09/T18 记录预期/实测。

重审条件：adapter 接纳不能去重、停止期限不能满足、模型推理持续过时。应先调整前缀/部署，再按流程修订需求，而非放松门禁绕过失败。
