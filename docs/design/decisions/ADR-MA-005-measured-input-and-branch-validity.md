# ADR-MA-005：实测输入接入与恢复分支有效性

日期：2026-11-08。状态：组长授权下采用的设计决定，队友可审核；不代表共同签核或新仿真实验通过。

## 证据与问题

PR #10 已提供运行时关节 profile、实际组件命令/反馈、可见相机图、折叠取景、投影检查、组件撤权/停止窗口和初态重置诊断。马的离线接入核验见[接入结果](../../research/runtime-component-integration.md)。组件命令前没有对应 RGB；沉降后的网格最大差异为 31.3663 和 31.6838 mm。初态坐标近似一致不足以证明失败中段的布料、速度、接触和随机状态可以恢复。

## 备选与选择

| 决策 | 选择及理由 | 代价／重审条件 |
| --- | --- | --- |
| 命名动作表示 | 使用带侧别、内容指纹和掩码的绝对关节目标；未知通道不补命令 | 180 维包含显式掩码；仅适配已知单关节目标，其他动作原语另定版本。端点内不等于路径可执行 |
| 决策时间边界 | 动作后图像仅供检查，禁止回填动作前输入；旧轨迹的关节顺序仍未验证 | 当前样本不能训练视觉动作选择；需要新增动作前同步采集，不扩大旧数据的已知范围 |
| 停止证据 | 接受组件测量，保留产品级联调门槛；队列字段按来源声明标注 | 不再把“无任何停止记录”列为风险，但也不将单进程探针等同于异步协调器保证 |
| 恢复候选配对 | 在中段快照、速度、接触及被动接续检查通过前，不用不同重置实例冒充同一失败根的反事实候选池 | 先做无动作重复接续，保留最大/RMS误差、持有/接触、阶段和结果；允许误差需按任务尺度与被动结果预先确定并版本化 |
| 精确重置不可行的后备 | 做按衣物/阶段/扰动条件分块、预登记顺序的独立实际试次，报告组间试次结果和重置不确定性 | 不能将独立试次硬塞进同一 `root_id`，不能据此计算同起点候选 oracle/选择率或宣称精确因果效果；现有完整候选池工具不接这种数据 |

本决定不禁止探索中段恢复；它要求探索结果与可确认的同起点比较分开。只有误差与接触验证足以支持所作主张，才启用同根候选排序诊断。若始终不能形成可比候选池，先比较实际闭环策略，再调整问题与统计设计，不能靠扩大网络掩盖实验单位错误。

## 已可由组长确定的评价与记录细化

- **CR-01：accepted-design。** 开发版校验拒绝记录保留 request/task ID、START/RESUME/RETURN 来源、失败检查码和用户提示；启动被拒只生成请求记录。它细化现有拒绝原因和日志设计，不改变 SRS 的 30 项需求或 18 项通过条件；实际持久化仍待实现。
- **CR-02：accepted-design。** 开发案例记录人工首次认为需干预、系统首次报警、控制器接受停止请求三个时刻，各带时间域、证据和缺失原因。人工项仅作离线标注，未知必须保留；没有时钟映射不计算跨域差值，不新增运行时人工判断环节，不改 T03/T18 阈值。
- **局部诊断口径：采用 S/A。** 一次已接受派发计一个动作，A=S+F+U；主要展示“已证实局部恢复占比”S/A，并列可判定覆盖 (S+F)/A。S/(S+F) 只能标为可判定动作条件比率；U 不改写为失败标签。不用该按动作比率替代 AI03 按试次自主成功率。

这些决定关闭设计待拍板项，不能替胡签署标注或用户走查，也不能替张确认未实现的接口。实际标签和产品验证按原责任完成。

## 对后续和课程的影响

H1/H2 目前仍未定，保留最小模型/可替换评分接口；不发布恢复性能。MR06/MR08/MR10 分别更新为“组件已有证据、产品级缺口”“已测得重置偏差”“已有部分资源采样但无训练吞吐”。Design 可展示已发生的诊断如何约束选择；全组实际排练、课堂反馈与 Canvas 提交仍需真实发生。
