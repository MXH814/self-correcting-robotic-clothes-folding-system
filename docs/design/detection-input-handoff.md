# Pre 检测接入：缺少 SADP_G 权重如何处理

更新：2026-11-08。本文澄清当前接入目标，不代表检测器、校准或在线 A/B 场景已经完成。

## 决策

保留正在运行的 GAM＋脚本正常控制器。本次优先适配 FIPER 的 **RND-OE 观测异常分支**，不把完整 HALO/SADP_G 策略权重设为前置，不伪造随机动作预测。独立视觉编码器替换策略特征属于适配，必须与原论文完整 FIPER 区分。

作者仓库 `learnsyslab/fiper` 的 `configs/eval/rnd_oe.yaml` 只要求 `obs_embeddings`，不使用 action batch；`rnd/rnd_models.py` 中 `RND_OE.datasets_to_model_inputs` 也只读取该特征。已检查版本：`13d79c5c3069def843e454787ff128defc249838`。

完整 FIPER 的动作不确定性分支仍需要生成式策略的真实动作采样，这部分当前不接。缺少 SADP_G 阻塞该分支，不阻塞独立视觉特征的 RND-OE 适配。

## 张茗博现在交什么

1. 先交一份已有正常运行的连续 RGB 记录及对应观测时间、试次 ID、图像形状和相机配置。尽量复用现有文件；先不重训策略。
2. 说明当前控制阶段、预期持有/提起/计划释放的阶段入口。阶段是任务上下文，不是故障标签。
3. 给出可取得的手部位置、衣物可见几何或仿真几何观测，分别声明来源，用于独立的规则对照和恢复检查。
4. 核对现有记录是否与当前固定相机一致。若没有足够的同配置独立正常试次，再补正常运行，分开拟合、校准和开发验证用途，不用同一视频切片冒充多个试次。
5. 接好检测输入及日志出口后，等马交可调用检测器、胡交实际参数/阈值文件，再接 A/B 实验。缺文件时继续保持 UNKNOWN 和拒绝自动恢复，不人为填数让检查通过。

没有独立编码器时，先导出原始 RGB，不要求张自己制造 `obs_embeddings`。编码与在线接口由马负责，胡按相同编码接口进行离线拟合、校准和验证。

## 马祥珲和胡知鱼分别补什么

- **马：** 确定并实现编码路径、RND 推理接口、版本绑定、历史窗口及缺测处理；接恢复触发、恢复后检查和规则对照。记录与作者方法的差异，不把分数当故障概率。
- **胡：** 核数据兼容性和试次划分，实际运行正常数据拟合、独立校准及离线验证，交参数/阈值/版本/运行命令；制作正常与异常的分数曲线、报警点和独立案例审核。
- **张：** 采集/导出真实观测、接仿真入口、执行 A/B/C，保存原始记录与结果。无需为了检测临时换控制策略。

## A/B/C 的准确含义

| 场景 | 现在能做什么 | 不能提前声称什么 |
| --- | --- | --- |
| A 正常 | 准备连续正常观测、核阶段；检测器准备好后检查误报 | 缺模型/阈值时全部 UNKNOWN，不算正常检测通过 |
| B 异常与恢复 | 准备异常观测及恢复入口；检测器接入后由真实告警驱动恢复 | 注入后定时恢复不算观测触发；不预设 RND 必然检出 |
| C 缺失输入 | 验证缺模型、缺阈值、缺图像等情况下拒绝盲目恢复并请求帮助 | C 分支通过不能证明 A/B 或完整产品闭环通过 |

即使观测 OOD 分支没有可靠分离度，也如实报告；可用单独验证的几何规则演示有限闭环，明确实际方法。需要展示的仍是设计进展，不能把适配版、规则备用或离线回放写成完整 FIPER 实测。
