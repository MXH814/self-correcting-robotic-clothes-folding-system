### 重跑与交给马的加载入口

在仓库根目录操作。Python 3.12、CPU torch 2.11.0、NumPy 2.4.4、Pillow 12.2.0。将 #18、#22 原包分别按[清单](../../configs/research/pre-observation-rnd-v1.json)中的 `path` 解压为子目录，#24 直接解压到完整链目录，使其中可见 `manifest.json`。请使用新的输出目录。首次获取官方编码器约 45 MB，程序会核完整 SHA-256。

```powershell
python -m research_tools.detection_encoder fetch-weights --output resnet18-f37072fd.pth
python -m research_tools.pre_observation_rnd --weights resnet18-f37072fd.pth --first D:/evidence/first --near D:/evidence/near --full D:/evidence/full --output D:/evidence/hu-pre-output
```

以下是离线输出头的最小加载方法，`rgb` 取 #18 原包的单帧 uint8 数组。加载时核随机初始化和编码器指纹。

```python
import torch
from research_tools.detection_encoder import FrozenRGBEncoder
from research_tools.pre_observation_rnd import load_head

encoder = FrozenRGBEncoder("resnet18-f37072fd.pth")
model = load_head("prototypes/ui/replay/detection-data/first-sleeve-fixed.pt",
                  "first-sleeve-fixed", encoder.reference)
with torch.inference_mode():
    score = model(torch.from_numpy(encoder.encode([rgb]))).item()
```

**给张的补采项。** 在 #24 实际相机和正常控制器下，提供独立正常拟合、校准及开发复验至少各一条。数量仅够走通流程，未达到统计评估规模。每条应附试次/血缘 ID、相机内外参和照明、渲染及读取时刻、连续 RGB、计划 HOLD/LIFT/RELEASE 和源指纹。有包后按马的 `observation_detector fit` 生成其所需的模型和阈值，再用新 A/B 记录检查误报、漏报及触发来源。眼下的开发输出头不能装成该包。新仿真可把同试次的检测与几何报告、恢复事件 JSONL 导入回放。页面按观测 ID 匹配，多种方法分别显示；无观测 ID 的恢复条目只按导入顺序展示。
