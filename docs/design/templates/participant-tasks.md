# 折衣工作台体验任务单

请想象你在家使用一台自动叠衣设备。今天体验的是电脑上的本地原型，桌面图和设备反馈均为模拟。我们想了解界面有没有把“机器正在做什么、何时轮到你操作、最后叠得怎样”说清楚。预计用时 10–15 分钟。

### 开始前，请听完说明再决定

参与完全自愿。你可以跳过问题、随时暂停或退出。主持人只用匿名编号记录操作顺序、用时、遇到的困难和你愿意分享的意见，用于本组课程设计改进与匿名汇报。我们不收集姓名、联系方式或学号，不录音录像。需要撤回时，可在本次记录匿名汇总前向主持人报出自己的编号。若不同意，请到此结束。

由参与者口头选择，主持人在匿名记录表登记：□ 同意参加并允许上述匿名记录　□ 不同意参加

### 请完成这四件事

| 任务 | 你想做什么 |
| --- | --- |
| 1　开始叠衣 | 桌面已经清空，一件展开、无结的上衣已经放好。请从眼前的页面开始一次折叠。你从哪里看出设备已经开始工作？ |
| 2　看懂异常 | 运行途中，衣物有一部分滑动了。请说说系统现在在做什么。假如你想亲自检查衣物，怎样让设备安全地等你？什么时候可以动衣物？ |
| 3　帮助后交还 | 请在原型中亲自调整一次衣物，并让系统接着折。如果系统提示位置还不合适，请按你的理解处理。说说何时是你在控制，何时已经交还。 |
| 4　查看结果 | 任务结束后，请判断三个问题：运行结束了吗？衣物质量合格吗？这一次算机器独立完成吗？请找到一条帮助你作判断的过程记录。 |

请按自己的理解操作。界面下方“测试桩”由主持人负责；遇到拿不准的地方，可以说出你在等什么或问主持人。结束时请告诉我们：**哪一处最费解？如果只能改一处，你希望改哪里？**
