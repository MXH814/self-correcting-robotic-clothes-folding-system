# 项目路线图

当前执行依据为 [第一阶段：研究问题验证与系统设计](first-stage-plan.md)，其中明确三人分工、近期文献、research gap 诊断、课程 Design 交付和验收。

第一阶段主要覆盖 G1，并推进 G2 的设计与最小集成；G3 和 G4 属于后续完整训练及正式比较。阶段按证据验收推进。正式 Design 细则尚待取得并核对，团队设计清单不代表教师评分细则。

| 阶段 | 负责人 | 验收证据 |
| --- | --- | --- |
| G1 环境与接口 | 张茗博主责，马祥珲确认算法输入输出 | 可复现的机器人衣物操作、固定版本、相机及动作协议、重置/停止验证 |
| G2 系统基线 | 张茗博、胡知鱼 | 前后端连接；正常叠衣、暂停、终止、接管、回放；状态与停止测试 |
| G3 恢复模型 | 马祥珲主责，其余成员支持采集与审核 | 两类失败数据、冻结划分、规则基线、学习模型与验证记录 |
| G4 比较与演示 | 三人共同 | 三方法×三条件×至少20次有效试验；完整结果、排除记录和演示 |

## 当前优先事项

1. 验证候选仿真环境与衣物资产兼容性，不把论文中的环境当作本地已经可用。
2. 统一观测、动作、任务状态和轨迹格式，先用简单控制器完成可复现操作。
3. 前端接入测试接口；开展潜在用户访谈并保存匿名记录。
4. 完成正常任务闭环后，再扩大失败数据采集和模型训练。

180 次是当前 SRS 规划的项目正式比较最低规模，不包括训练、调试和验证运行；不是已发布的独立 Design 要求或论文充分性保证。
历史信息与候选排序的独立贡献需另做消融实验才能判断。
