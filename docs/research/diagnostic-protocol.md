# 开发诊断与后续实验协议

状态：研究方案与离线软件已形成，真实恢复数据尚未采集/诊断。环境已按[ADR-MA-004](../design/decisions/ADR-MA-004-simulation-platform.md)选定；张已有示范与训练小试报告，不等于恢复验收。负责人马祥珲；胡知鱼审核标签，张茗博负责可重现运行。本协议与 SRS 后续 180 次正式比较分开。

## 1. 启动前检查

1. 固定正常控制器、仿真/资产、机器人动作映射、相机来源、代码/依赖与预算清单；验证正常任务和合法释放。
2. 从开发衣物收集抓偏与部分滑移；允许自然失败，注入标签与实际 DR02 标签分开。参考 30–60 个根失败状态，按可用性调整并保留不足；不是统计充分性承诺。
3. 保留不同阶段、恢复成功/失败、遮挡与普通正常动作。歧义与缺证据单列，不靠删除难例提高成绩。
4. 先按 garment/root trajectory/branch family 分组，再进行训练/开发验证划分。后续封存终测衣物和种子不访问，不参与检索库、校准、归一化或阈值选取。

## 2. 数据记录的最小契约

| 粒度 | 必需内容 |
| --- | --- |
| 根试次 | purpose、trial/root/family ID、garment、method、condition、seed、snapshot、代码/资产/控制器/模型/阈值版本、预算 |
| 观测/历史 | camera/proprio 来源、frame/command ID、sim time 和 monotonic wall time、阶段、已执行动作、可见性与缺失值；显式区分 online/offline |
| 恢复决策 | decision/generation、检测结果、候选集及拒绝原因、评分语义/校准版本、选择、accepted dispatch ID、尝试数 |
| 分支结局 | 实际执行量、局部 label、接续控制器、运行终态、help/assistance、离线质量、整任务标签、耗时/费用/异常/审核状态 |

每个候选一行，但仅已接受派发有 command ID。禁止把未执行候选标为实测成功。视频/网格/权重在受控存储，索引保留相对引用、哈希和时间范围。

## 3. 分支与动作预算

复用同一初态、候选池、接续控制器和剩余预算。必须验证快照恢复布料、速度、接触、随机状态和相机；仅恢复关节角不算同状态。不能精确快照时量化重置误差并用配对组分析，不声称精确反事实。

候选最多 8 个；正式运行每任务最多 3 次恢复、300 活动仿真秒及费用门禁。开发候选分支用于诊断，不把多分支最佳轨迹包装成单次自主运行成绩。物理时间、推理时间和计费时间分别记。

## 4. H1 信息消融

使用 B0/B1/B2/B3/B4，定义见 [问题卡](hypothesis-cards.md)。保持 candidate IDs、标注、训练预算、编码器基础与划分一致。输出不同输入成本与延迟；不能把不同控制器增益归因给历史。若 GRM/特征使用完整轨迹未来，只能生成离线监督，不得以相同字段输入在线模型。

真实环境另纳入SADP原生3帧观测时序对照；四帧历史胜单帧不构成创新证据。H2补阶段/图剩余代价代理，工具字段stage_cost_score与其他候选使用同一可用输入；不是AgentChord原框架复现，参考[接入设计](dex-integration-plan.md)。

未获得标签前确定主要指标和比较；探索阶段可修改设计，但记录修改，修改后不能将同一探索集宣称最终验证。开发方差大则扩大独立根状态/种子，关联帧不当独立样本。

## 5. H2 局部与最终交叉核对

先按 SRS DR05 与胡知鱼规范检查局部恢复，再由固定正常控制器继续；最终标签遵循 AI02/AI03 的合取条件。构造局部成功/失败或未知 × 整任务成功/失败或未评估表，未知单列，报告样本与覆盖，不强制填成失败质量。

主要结果以全合格分支/试次为分母，同时报告“候选池有好动作”的条件选择率；不能只报条件率。方法导致的物理发散保留为方法失败；环境无效须有被动/基线复现和审核，替补保留关联。

## 6. 统计与资源

先登记可承担的独立初态与训练种子；探索试跑估计波动和实际 wall time，再冻结确认实验规模。报告原始计数、各衣物/阶段、配对 win/tie/loss、95% Wilson 成功率区间；成组 bootstrap 如使用，按根状态/衣物抽样，不按帧。区间不能替代训练多种子或证明总体泛化。

记录采集、预处理、训练、推理和评测的 GPU/CPU wall time、存储、已付/估计费率。仅在环境可用、数据口径固定及控制预算批准后启动付费任务；本次文档工作未启动 GPU 租用。

## 7. 保留/停止条件

继续 H1：信息消融收益不能被阶段/容量解释，且闭环恢复具有一致方向的证据。继续 H2：真实存在局部/最终目标冲突，简单评分不足且候选池有空间。未定：样本/基线/正常控制能力不足。否定：对照解释全部收益或复现不了关键现象。

门槛由试跑后记录的最小有用效应、成本与方差共同确定，不预先编造提升数字，不以挑种子/重复测试到显著为目标。论文确认实验与课程 180 次协议各自冻结和报告。
