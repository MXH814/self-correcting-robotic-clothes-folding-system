## 最容易误用的时间边界

实际命令发起于约 0.533 s 仿真时间，唯一新 RGB 渲染于约 1.483 s、读取于约 1.533 s。它不能解释“在 0.533 s 时用图像如何选择这条动作”。约 50 ms 是该帧渲染到读取的仿真差值，既不是墙钟推理时延，也不是相机与协调器的同步误差。

因此输出中的 `pre_command_rgb_available=false`，所有关节观测行的 `rgb_feature=null`。相机检查特征与动作前决策输入分开，`executed_action_history` 和恢复标签保留未知。API 返回与后续位置变化可以支持这次组件命令的检查，不能补出产品协调器的执行片段、实际执行量或完整动作历史。

```powershell
python -m research_tools.runtime_intake --sample docs/research/zhangmingbo/runtime-io-camera-20261108/sample.json --control-evidence docs/research/zhangmingbo/fold-experiments-20261108/control-evidence.json --output-dir runs/ma-runtime-intake-new

```
