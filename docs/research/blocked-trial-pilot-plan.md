# 中段不可比时的独立分块先导方案

2026-11-08，马祥珲负责的实验设计补充；研究方案，尚未执行，不替代 SRS 正式三方法验收。依据 ADR-MA-005 和已审查的 PR #14/#15 草稿：它们已提供衣物扰动和中段重放初探，当前仍有字节交接修正，W0/接触/DR02标签未齐。PR #15 报告中段最大网格差约30.5/70.7mm，布料状态写入未成功。

## 当前决定

这些重复运行按各自真实轨迹保存，不建立“完全相同失败根”候选池，不运行同根候选 oracle/排序选择率。继续补中段状态恢复有价值，但无需把彻底解决该接口设为所有设计工作的前置。可以先准备独立实际试次的分块、随机顺序和完整记录，检验执行流程及实际方法的结果。

这不是认定三个轨迹统计独立。重置不完全可能带来顺序、接触缓存或前一试次的遗留效应；随机排列方法本身不能证明这些效应已消除。

## 单位、分块与顺序

- 一个实际启动并执行的轨迹为一个试次，独立 `trial_id`；同一动作前状态未获恢复证据时，不给多次运行共用 `root_id` 冒充候选分支。
- 分块字段在运行前确定：衣物实例、名义阶段/控制前缀、扰动条件和幅度、控制器/场景版本、预算及已知随机设置。名义分块不代表物理状态相同。
- 预登记各方法的执行顺序和随机种子，保留运行序号、前一试次方法、初始化/沉降时间。暂停后是否重建场景、如何检查稳定由张提供实测入口，先检查遗留效应再冻结方案。
- 所有方法采用同一正常控制器、动作范围和预算。既有“无自动恢复、固定重试、拟议学习恢复”仍是正式方案；学习方法未就绪时记未执行，不生成其结果。

## 起点与执行证据

每个试次保留动作前可见RGB、命名关节和时间域，另存离线网格/速度/持有或接触状态及其指纹。起点摘要使用动作前已获得的量；不得按方法执行后的结果挑选“更相似”的试次或删除困难初态。

需要张提供原始中段位置/速度数组及双臂状态快照（受控存储、相对引用和SHA256即可，不要求大数组直接入Git），以便独立复算误差。只恢复关节角、只比较目标衣片高度或仅重复名义前缀均不足以认定相同起点。若不能排除明显顺序/遗留效应，结果保持探索性，不能直接归因为恢复方法的因果收益。

DR02仍需已注册W0、阶段持有/合法释放、接触或漂移证据与持续窗口，胡独立审核；“提前开手”是注入条件，不自动等于“部分滑移”真值。起点无效和方法执行失败保留原记录，按预登记资格规则分别处置。

当前注入类名也不直接作为目标标签：横移后目标衣片未抬起可能是漏抓，尚无接触中心支撑“抓偏”测量；提前开手是受控失持，不能自动代表夹持仍有效时的自然滑移。手指几何中点是漂移参照，不是实际接触中心。补合法释放对照，防止检测器只学会识别开手或阶段变化。

注入开关、12个仿真顶点和最终结局只用于离线审核，不进入部署特征。后续训练必须保留相机/本体来源边界，避免把故障生成机制泄漏给模型。

## 结局与分析边界

1. 固定首袖接续可先检查脚本是否跑通，但要评整任务需固定完整接续入口和质量证据；高度上升只作几何描述，不生成自主成功。
2. 局部标签按S/A、F/U与覆盖率分别报告；整试次保留完成、独立质量、求助/人工、预算和未知。未执行/未知不补成成功，也不偷偷当作负标签。
3. 方法比较按实际试次汇总，附分块/顺序/初态差异。当前单一衣物和少量重放不能支持未见衣物泛化或稳定显著性主张。
4. 原有 `diagnostics.py` 的同根候选池/配对接口不接受这类独立轨迹；需在数据结构和独立单位明确后另实现试次级分析，不直接把行改成相同root就运行。
5. H1的历史信息作用与H2的局部/最终目标冲突依旧待验证。本方案先改善有效试验的组织，不能仅凭设计文件认定创新成立。
