## 方法和审核状态

RND 检测只读当前 RGB 编码、过去五帧和允许的正常控制阶段。左右袖分别校准。原始分数及 ANOMALY 保留在事件中。

B 恢复后使用仿真内部材料片／指尖几何确认连续持有。新代次建立基线后，左袖固定接续的每个 RGB 检查点还需新几何 HELD。几何或 RGB 证据失效则求助。计划释放结束该检查，右袖继续按 RND 判定。
