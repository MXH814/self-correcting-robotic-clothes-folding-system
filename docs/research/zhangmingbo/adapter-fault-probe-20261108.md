## 复跑

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\simulation\run_local.ps1 -Stage runtime-fault -Headless -OutputRoot 'E:\Robotics\runtime-adapter-fault-results'
```

输出位于每次运行的独立目录，`control-evidence.json` 包含事件与速度样本，`control-events.jsonl` 是运行中的事件日志。实际模拟断开通过本地故障注入触发，适配器由同一进程通知并保持位置。真实跨进程心跳超时、进程崩溃后的安全停止、重启恢复和产品协调器联调仍待验证。抓偏、滑移与恢复候选也属于后续独立实验。
