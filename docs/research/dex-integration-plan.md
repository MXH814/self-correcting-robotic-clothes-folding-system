## 2. NPZ导入边界

第一步可安全查看文件结构：

```powershell
python -m research_tools.dex_dataset --input <trusted-local-trajectory.npz> --output <new-header-report.json>
```

该命令只读ZIP/NPY头部和文件hash，不解包到磁盘、不反序列化pickle、不读取数组payload；会拒绝过多条目、超大声明解压量和过大头部。**只证明容器/头部可读，不证明轨迹完整、CRC正确、标签有效或观测可部署**。对象数组内字段保持未知；不提供“开启pickle后自动当在线数据”的快捷通道。

第二步由采集机在可信来源和固定依赖下导出纯数值/图像引用及JSON元数据。此导出器现已实现，作者已生成两个正常包且本机已接收校验，不再列为待编写；旧数据实际缺失的动作/时钟/标签保持未知，下表所需在线字段由新采集补齐。官方原始数据保持只读，避免上游转换器覆盖现有Zarr。

## 3. 原字段到研究输入的映射

| 来源字段/能力 | 当前判断 | 处理决定 |
| --- | --- | --- |
| image | 报告称相机RGB；时间戳/外参未齐 | 作为首选视觉来源候选，补相机ID、wall/sim时间、遮挡/丢帧、resize/encoder版本 |
| joint_state | 报告称存在，顺序/单位未冻结 | 核真实profile后进本体状态；不直接将60维向量当合法动作 |
| garment_point_cloud / env_point_cloud | 尚不清楚由深度重建还是直接网格采样 | 默认隔离在offline evidence，不进在线特征；来源证明为相机深度后才能放行 |
| points_affordance_feature | 可能含GAM/示范点/特权点信息 | 固定checkpoint与点源，未核明前不得混为纯视觉输入 |
| pos / ori / usd_path | 初态/资产索引与场景元数据候选 | 离线分组/审计，不当模型识别衣物ID或读取隐藏状态的捷径 |
| 原NPZ无时间戳 | 不能恢复准确新鲜度、连续历史与停止窗口 | 历史示范可受限做离线预训练，不能伪造wall时间；新采集需真实双时钟与命令ACK |
| final result: True | 官方内部判定 | 保存upstream_success，不替代runtime_completed、SRS质量、assistance/autonomous_success |

## 4. 独立评价与数据划分

论文面积>85%、作者本地点云比例≥88%及SRS质量是不同定义，分别保存而非改成一个“success”。具体本地代码差异仍待源片段核查。完整自主成功需要运行完成＋SRS离线质量＋无求助/人工介入。

官方正常示范不是恢复成功样本，也不自动包含失败标签。若给当前研究做编码器/正常控制训练，先从资产路径建立衣物ID映射并对train/development/sealed test消重；轨迹内随机2%验证不能证明未见衣物泛化。不能用看到过的官方验证衣物作为“封存未见”。

根失败状态、候选分支族、正常示范血缘和衣物均须关联；先划分再建检索、归一化与校准。真正独立单位不足时保持未定。现有训练试跑验证的是链路而非恢复效果，不纳入H1/H2结果表。

## 5. 必须补强的研究对照

- SADP原论文已有3帧观测上下文，因此B0单帧只是诊断下界，不能靠击败B0宣称创新。真实实验应加入匹配原生时序输入的基线，比较额外已执行动作/接触经历是否提供独立收益，记录对齐、容量、FLOPs和延迟。
- AgentChord已有前向图恢复；H2不能宣称首次保留任务进度。需要比较简单任务阶段/剩余图代价与衣物物理质量/最终延续，证明图上的进展与实际折叠存在具体差异。
- 新增`stage_cost_score`可选诊断列：取执行前可计算的负剩余图代价，同一合法候选池和预算。若不能计算，不填虚构值。该列需全数据一致提供；无它也能运行原诊断。它只实现代价排序代理，不是AgentChord完整约束编译/监测或原论文复现。
- `forward_stage_score`纯函数可检查两项非负图代价的前向条件并返回负代价/None；None不是0成功概率，也不能跳过恢复门禁。它不估计未来真实折叠结果。

## 6. 环境交接后可直接执行

1. 保存已有配置、源码归档、资产清单和日志指纹；从配置读运行根目录，在隔离新输出目录复跑组件/正常流程，不调用会覆盖历史数据的转换脚本。
2. 导出一条纯数值/图像引用的正常记录，核相机来源、动作语义和双时钟。然后才能实现真实feature_version与研究JSONL导出器。
3. 用受控偏移/滑移记录证明扰动生效、DR02标签和稳定窗口；检查未扰动对照，量化重置误差。
4. 运行同起点、同候选和固定接续流程，补真实局部/最终标签；先检查候选可达性，再跑B0–B4、stage-cost代理及最近邻适配。
5. 稳定小试后用真实吞吐/报价估算资源，不照搬单阶段单种子的短测外推，也不因本地慢就先扩大训练。

需要交接的最小文件是包装脚本/修改清单、资产与版本清单、一个正常轨迹及图像、动作/观测/停止样例、运行输出位置。无需把大型安装包或权重提交Git。独立复跑与实物停止验证仍不能由文档审查替代。
