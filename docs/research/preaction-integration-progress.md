## 原始字节和 Git 交接修正

本轮发现：Windows 工作区的 CRLF 原始 JSON 与 Git 自动归一化后的 LF blob 字节不同。原清单绑定的是实际采集文件字节，其他检出设置可能无法通过指纹检查。已对四个实测目录的 JSON/JSONL 设置 `-text`，保留原始字节，并逐文件确认解析后的测量值完全相同。

验证不只读取当前工作区：从 Git 暂存区的原始 blob 导出 PR #13 全包后，再用新接入工具检查，6文件清单和492维输入均通过。原始实测数值、记录ID和清单中的指纹未改；不是把不匹配的文件重新包装成一次新实验。后续新增实测目录也应明确保留原始字节或采用预先约定的规范序列化，避免隐式换行。
