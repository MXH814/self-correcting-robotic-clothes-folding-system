当前输入为312维：192维固定RGB网格均值及120维命名关节q/dq。已记录的多关节绝对目标编码为180维掩码/目标/相对当前q的差。四步过去视觉/本体为1248维；四个已有后续观测的历史命令为964维，每项包括180维命令、60维关节变化和一个仿真时长。历史不足时补零并带掩码。

动作历史只采用当前源观测之前已经取得后续观测的命令；不包含当前命令、未来命令和待反馈命令。同一步多条命令可能共享反馈，关节差分不能归因为某一条命令的独立物理作用。重复读取同一渲染帧不伪造成多帧视觉历史。条件名、注入阶段名、隐藏网格、接触代理及最终结局均不进入数值特征。实际产品控制代次与预算未在该记录中采集，保持未知，不伪造。

四个较早ZIP的trace缺少target_units元数据。接入时显式引用作者在固定版本README中对SDK绝对关节目标为rad的声明，并以source_trace_sha256绑定原数据；不修改原包，不从最新采集代码倒推旧元数据。最新闭手重抓包自带声明。此为离线来源声明，不等于通过产品动作profile/限位验收。

## 3 本轮核心算法实现

- [garment_trace_intake.py](../../research_tools/garment_trace_intake.py)：原始文件校验、时间/身份/通道检查、因果历史和真实输入导出。
- [recovery_candidates.py](../../research_tools/recovery_candidates.py)：显式的“释放—退让—重新抓取—抬升”宏提案，编码双臂选择、三个世界坐标位置、wxyz姿态和等待步数，共17维；验证单位、姿态、试次和提案可用时刻。它编码候选，不自动证明动作合法、生成最优动作或派发。
- [sequence_ranker.py](../../research_tools/sequence_ranker.py)：视觉/本体历史及动作历史各用一个带掩码GRUCell，融合当前观测与候选后输出原始logit；提供current-only对照入口。它是可替换的初始实现，不是已成立创新，尚未适配原生SADP/RedFlow强基线，也没有容量/计算预算公平比较结论。
- [trial_outcomes.py](../../research_tools/trial_outcomes.py)：按实际试次和条件描述结局，拒绝重复trial_id及未经审核的自主成功标签；未知与失败分开，不调用同根候选选择率，不预设统计独立或报告因果收益。

训练只接受[独立的恢复样本契约](recovery-sample-contract.md)，不是直接读取946条派发后粘贴试次标签。模型目前要求固定的接续控制器/目标/预算上下文；若需跨阶段、上下文或预算学习，先扩展显式条件和数据契约。只在训练数据拟合归一化；按试次/关联分支族隔离开发集。未训练/未校准的模型没有产品派发权限，排序logit不进入0.60概率门禁。

## 4 复用入口

原包下载至受控本地目录，先核对[Release清单](zhangmingbo/garment-observation-20261108/trace-packages.json)和各包manifest，再调用：

```powershell
python -m research_tools.garment_trace_intake --input-dir <已核验的某个试次目录> --output-dir <新的输出目录> --position-unit-source "author SDK radians declaration: garment-observation README@639c824"
python -m research_tools.trial_outcomes --full-fold-dirs <完整试次目录1> <完整试次目录2> --output <新的汇总JSON>
python -m research_tools.sequence_ranker --input <审核后的恢复决策JSONL> --checkpoint <新检查点路径> --epochs 30
```

第三条命令是后续复用接口，当前没有合格真实训练集；直接喂dispatch-inputs.jsonl会被拒绝。本轮特征在忽略目录`runs/ma-garment-intake-20261108-v1/`，原包在`tmp/pr18-packages/`，Git仅保留代码及小型审核摘要。命令不发送机器人动作。
