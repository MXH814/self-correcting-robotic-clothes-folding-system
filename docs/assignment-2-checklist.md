| 交互 | Start；正常/恢复；Pause/Resume；停止与终止；人工接管/返回；模型激活；包括异常、超时、旧结果 | 张茗博、胡知鱼、马祥珲 |
| AI/agentic 关注点 | 明确是否为工具调用型 agent；即使无 LLM agent，也具体说明策略/协调/执行职责、工具契约、历史与状态、编排、边界、人工监督、超时/预算/回退 | 马祥珲主责、张茗博协作 |

不为贴合 agentic 标签增加多智能体。报告说明系统实际类型，并针对适用的自主执行风险给出设计；Part III 用 agentic development 开发是另一件事。

建议 ADR 每项使用：背景/目标、约束、备选、比较依据、决定及理由、代价/弱点、验证方式、重审条件、状态。重要选择具体说明，次要选择允许后续演进。

## 4. 从研究到课程设计的共同成果

- 文献矩阵 → 技术能力与限制 → 备选方案/ADR → A2-02、A2-06、A2-08。
- 失败诊断 → 需求缺口与研究假设 → 需求变更/策略接口 → A2-03、A2-04。
- 仿真试跑 → 部署条件、动作/观测契约、吞吐与风险 → A2-02、A2-06。
- 评价与案例审核 → 数据设计、结果标签、用户流程与后续验证 → A2-03、A2-05、A2-06。

实验不支持原假设时，仍可完成合格 Design：保留可替换恢复接口、采用明确的简单基线、解释取舍，将待证研究方案列为 Part III PoC。不得让某个研究模型未训练成功阻塞九项交付。
